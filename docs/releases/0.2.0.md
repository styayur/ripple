# Ripple 0.2.0 — Unified Graph Workspace

## Overview

Ripple moves from a bounded sidebar preview to an independent Obsidian graph
workspace. Four distinct rendering modes consume one Vault index, relevance
filter and selection state. No upstream graph plugin needs to be installed.

## Highlights

- Immutable revisioned graph model and incremental metadata/link updates.
- Full workspace graph navigation, note opening and node inspection.
- Frontier, Dense, Cluster and actual 3D Galaxy views.
- Identical relevance eligibility and preserved selection across modes.
- Independent cameras, Frontier drag/pins and workspace-state restoration.
- Bounded opt-in local body indexing; no slider-triggered file reads.
- Self-contained production bundle, license inventory, reproducible build and
  cross-platform CI.

## View modes

Frontier uses a d3-force worker and Canvas navigation with draggable/pinnable
nodes. Dense uses a grid, batched points, viewport culling and label/edge LOD.
Cluster uses folder-seeded label propagation, visible convex hulls and
cross-community links; it is not Louvain or a crossing optimizer. Galaxy uses
Three.js, perspective xyz geometry, ray picking and OrbitControls, with a
deterministic spatial layout rather than 3D force simulation.

The modes share scoring and eligible nodes. Rendering budgets affect links,
labels and hulls only: Canvas modes draw up to 30,000 links and 120 labels;
Cluster draws up to 200 hulls; Galaxy draws up to 100,000 links, reduced to
5,000 above 10,000 visible nodes. Dense suppresses links below 0.3×.

## Compatibility

Real integration was exercised on Windows 11 with Obsidian API/app **1.14.5**
(desktop installer 1.13.7, Electron 43.3.0) in a newly created 32-note synthetic
vault and separate app profile. It covered loading, every mode, shared 65%
filtering, selection, real 3D rotation, independent cameras, note opening,
pins, themes, metadata updates, view restoration and plugin restart.

Other Obsidian versions, macOS/Linux host integration, mobile, other GPUs and
large real vaults are **NOT TESTED**. Linux/Windows CI and browser fixtures do
not substitute for those compatibility tests. Full evidence and synthetic
performance observations: [VALIDATION.md](../VALIDATION.md).

## Installation

Download main.js, manifest.json and styles.css into
`<vault>/<configDir>/plugins/ripple-graph-filter/`. Reload Obsidian, enable
**Ripple Graph Workspace**, then run **Open graph workspace**. Minimum app
version is 1.14.5. All runtime code, notices and worker source are bundled in
main.js; no extra asset chunks are required. Community directory submission
has not been made or approved.

## Known limitations

The index supports up to 50,000 Markdown nodes and resolved links. Body indexing
is limited to 32,768 characters/note and 8 million total. Attachments,
unresolved targets and Canvas cards are not indexed. Keyboard node lookup
lists the first 200 visible notes. Narrow the query for others.

Large software-WebGL context creation can be slow; synthetic 50,000-node runs
recorded long context-initialization stalls. Frame samples include outliers
and are not FPS promises. Active Frontier physics moves unpinned nodes and can
take time to settle. Unpinned positions are reseeded on reload; cameras and
pinned positions restore. There is no automatic bridge retention, 3D physics,
AI extraction, remote model service or automatic link writing.

## Privacy

Ripple initiates no network requests, telemetry or external service calls.
Indexes, body text, query and selection stay in memory. Mode, cameras and pins
are serialized by the official Workspace API. Original notes, frontmatter,
links, paths and other plugin settings are not written. Required runtime
libraries are bundled with their original MIT/ISC notices.

## Upgrade notes

The plugin ID remains ripple-graph-filter and the existing command/view IDs
are preserved. The display name is now Ripple Graph Workspace. Existing 0.1
leaves load the new view; move an old sidebar leaf into a main tab if desired.
There are no persisted 0.1 query/settings files to migrate. Four-plugin
discovery is no longer the primary UI: the modes are owned by Ripple and have
no runtime requirement for those plugins. Historical alpha assets/tags remain
unchanged.
